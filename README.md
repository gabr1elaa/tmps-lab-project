# myTasks — TMPS Labs

myTasks is a simple console task manager written in Java. It is a single project that grows with every TMPS lab. Each lab lives in its own folder and starts as a copy of the previous one.

| Lab | Topic | Folder |
|---|---|---|
| 1 | SOLID principles (SRP, OCP, LSP) | [lab1](lab1/README.md) |
| 2 | Creational design patterns (Singleton, Builder, Prototype) | [lab2](lab2/README.md) |
| 3 | Structural design patterns | — |
| 4 | Behavioral design patterns | — |

## Run

Open this folder in IntelliJ IDEA (it loads as a Maven project). To run a lab, open its `Main` class, e.g. `lab1/src/main/java/com/mytasks/Main.java`, and run it.

Requires Java 21 or newer.
